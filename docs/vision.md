# 产品愿景与需求（Vision & Requirements）

> 本文档由原始构想（原 `IDEA.md`）提炼而成，作为产品需求的**权威来源**。产品设计决策记录于「产品设计决策」章节（2026-08-17 定稿）。

## 一句话愿景

基于大模型的「J 人校园助手」：把散落在课表、Notion、Obsidian 里的信息自动融合，帮你排出**科学、合理、可执行**的每日时间表。

## 目标用户

- 计划型（J 人）学生：希望一切井井有条，讨厌手动排计划
- 平台：网页（Web + PWA），安卓手机与电脑浏览器通用

## 核心使用场景

1. **早晨**：打开网页，助手自动读取今日课表（如 5 节课：3 节水课 + 2 节专业课）
2. **课后**：用户在 Notion 提交作业任务，在 Obsidian 记录课堂笔记
3. **自动融合**：助手读取新任务与笔记，结合前几天的学习记录和用户提交的杂项安排
4. **科学规划**：基于艾宾浩斯遗忘曲线，评估「掌握知识 + 完成作业」所需时间
5. **呈现确认**：自动生成时间表并呈现给用户，询问「是否可行」
6. **习惯自适应**：根据用户历史习惯自动调整任务耗时预估，并主动提出建议

## 核心流程（时间轴定稿）

| 时间 | 环节 |
|------|------|
| 前一晚 21:00 | 助手预生成「明日计划」并推送，可睡前确认 |
| 07:30 | 打开网页，今日计划已就绪（课表自动刷新） |
| 07:31 | MCP 拉取：今日课表(iCal) / Notion 新作业 / Obsidian 新笔记 |
| 07:32 | LLM 提取知识点，标难度(1-5)，生成复习点 |
| 07:33 | 时间表规划：固定课程 + 作业 + 复习 + 杂项，不冲突排布 |
| 07:34 | 呈现计划 → 用户确认 / 拖拽调整 |
| 07:35 | 写入日历 |
| 22:00 | 用户标记完成 → 记录「预估 vs 实际」→ 校准模块学习 |

## 功能需求

| 编号 | 需求 | 说明 |
|------|------|------|
| F1 | 多源数据接入 | 通过 MCP 读取课表、Notion、Obsidian 中的日程与任务 |
| F2 | 知识提取 | 将课堂笔记切分为知识点，评估难度 |
| F3 | 复习调度 | 按课程档位 + 遗忘曲线安排复习，结合 deadline 反推优先级 |
| F4 | 时间表规划 | 融合课程 / 作业 / 复习 / 杂项，生成不冲突的时间表 |
| F5 | 用户确认 | 时间表先经用户确认 / 调整后再生效 |
| F6 | 习惯自适应 | 记录「预估 vs 实际」耗时，自动校准后续规划 |
| F7 | 主动建议 | 遗忘窗口提醒、任务过载建议、每日计划晨推 |

## 产品设计决策（2026-08-17 定稿）

### 复习策略：课程档位制（用户可自设）

| 档位 | 名称 | 复习序列 | 适用场景 |
|------|------|---------|---------|
| S | 核心课程 | 当天晚上 + 第 1/2/4/7/15 天；难度≥4 额外加一次 | 考研 / 核心专业课 |
| A | 标准课程 | 当天晚上 + 第 1/2/4/7/15 天 | 一般专业课 |
| B | 轻量课程 | 当天晚上 + 第 1/7 天 | 可听可不听的课 |
| C | 划水课程 | 不安排复习，仅跟踪作业 / 考试 deadline | 完全不听的课 |

- 每门课在设置页手动指定档位（一次设置长期生效），可随时调整
- **B/C 档课程的时间块默认释放**为可安排时间，用于作业、复习或其他事项
- 知识点难度 1-5 微调：难度≥4 → 首次复习提前至课后 2 小时；难度≤2 → 跳过当天晚上那次
- 每日复习上限：默认 8 个知识点，超出顺延次日（设置页可调）

### 界面（三页面）

1. **今日计划页（首页）**：AI 计划确认横幅（✅ 确认 / ✏️ 拖拽调整）+ 时间轴（课程 / 作业 / 复习 / 自由时间），复习点标注 🔁 与复习次数
2. **周视图**：7 天网格，课程 + 任务 + 复习点，一眼看清本周负载
3. **设置页**：数据源绑定（Notion OAuth / Obsidian vault 路径 / iCal 导入）、课程档位管理、个人偏好（学习时段、复习上限）、LLM 配置（豆包 / DeepSeek）

### 已确认的默认决策

| 决策点 | 结论 |
|--------|------|
| 计划生成时机 | 前一晚生成「明日计划」，早晨快速确认（可改） |
| 界面风格 | 简洁卡片风 |
| 每日复习上限 | 8 个知识点（可调） |
| 校准机制 | 记录「预估 vs 实际」耗时，按 课程 × 时段 × 难度 分桶统计 |

## 非功能需求

- **隐私**：个人数据（课表 / 笔记 / 日程）仅存本地或私有仓库；外部服务走 OAuth 最小权限授权；LLM 可配置为国内模型，数据不出境
- **可扩展**：新数据源 = 新增 MCP adapter，不改核心逻辑
- **单用户起步**：SQLite，零运维
