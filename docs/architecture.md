# 架构设计：Jren Campus Assistant

## 1. 设计目标

为计划型（J人）学生提供一个"会自动排日程"的校园助手。核心价值不是简单列任务，而是：
- 把散落在课表/Notion/Obsidian 的信息自动融合
- 用遗忘曲线科学安排复习
- 通过习惯自适应让规划越来越贴合个人

## 2. 六层架构

### 2.1 载体层（Notion Calendar + WorkBuddy，替代自建前端）
- **日程载体**：Notion Calendar（原生 App）——后端将计划写入 Notion 日程数据库，手机 / 电脑 / 平板三端同步，自带周视图、拖拽调整与事件提醒
- **AI 载体**：WorkBuddy（腾讯）——MCP 客户端 + 定时任务 + 微信远程；对话式确认 / 调整计划 / **一句话添加任务**（`add_task` → 本地 + Notion 任务库 + 自动排日程，Issue #55）
- **前端**：自建前端已移除（2026-08-18）；数据源绑定、档位配置等管理操作通过后端 API / WorkBuddy 完成
- **提醒链路（方案 A）**：WorkBuddy 微信推送为主（21:00 生成提醒 / 08:00 计划预览）；Notion Calendar 事件提醒双保险（电脑关机时云端兜底）

### 2.2 MCP 客户端层（数据接入）
- 统一通过 MCP 协议接入外部数据，未来加数据源 = 加 adapter，不改核心逻辑
- **Notion**：官方远程 MCP Server（mcp.notion.com/mcp），OAuth 授权，支持查数据库、读页面 Markdown
- **Obsidian**：obsidian-mcp-server，直接读本地 vault，全文搜索、读笔记
- **课表**：教务系统导出 iCal 或手动维护
- **日历输出**：CalDAV / Google Calendar（生成的日程写入处）

### 2.3 知识提取层（LLM）
- 输入：当天课堂笔记（Obsidian）+ 作业任务（Notion）
- 输出：结构化"知识点记忆单元"列表（知识点、所属课程、难度 1-5、关联作业）
- 用 LLM 结构化抽取，辅以规则兜底（如按标题/章节切分）

### 2.4 遗忘曲线调度器
- 基于艾宾浩斯遗忘曲线设定复习间隔：第 1 / 2 / 4 / 7 / 15 天
- 难度越高的知识点，前几次复习间隔越短
- 结合作业 deadline 反推：作业用到的知识点优先复习

### 2.5 时间表规划器
- 输入：固定占用（课表）、可变任务（作业/复习/杂事）、可用时间片、用户偏好
- 约束：时间不冲突、deadline 满足、复习间隔不重叠、学习时段偏好
- 输出：一版"建议时间表"→ 用户确认/调整 → 写入日历
- 规划器 = 确定性约束求解（保证可行）+ LLM 编排（处理复杂语义）

### 2.6 自适应校准模块
- 每次任务记录：预估耗时 vs 实际耗时
- 按 `课程 × 时段 × 难度` 分桶统计，动态修正时间预估
- 示例：连续 3 次发现高数作业实际是预估的 1.5 倍 → 自动上调该类任务预估

## 3. 数据流（一次完整闭环）

```
早晨打开网页
  → MCP 拉取今日课表（5节课：3水 + 2专业）
  → 课后：用户在 Notion 提交作业任务，在 Obsidian 记笔记
  → MCP 增量拉取新任务与笔记
  → LLM 提取知识点 + 难度 + 关联作业
  → 遗忘曲线调度器：为每个知识点排复习点
  → 时间表规划器：融合课表/作业/复习/杂事，产出建议时间表
  → 呈现给用户确认（可拖拽调整）
  → 用户批准 → 写入日历 → 次日提醒执行
  → 记录实际完成情况 → 反馈到自适应校准
```

## 4. 关键技术决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| MCP vs 直连 API | MCP | 统一协议、生态成熟、扩展数据源成本低 |
| 自建前端 vs 现成载体 | Notion Calendar + WorkBuddy | 日历与 AI 交互均用现成产品，开发成本趋近于零（2026-08-18 变更） |
| 遗忘曲线是否硬编码 | 参数化 | 初始用标准曲线，后续可随个人数据微调 |
| 规划器确定性 vs 纯 LLM | 混合 | LLM 做语义理解，约束求解保证时间表可执行 |
| 单用户起步 | SQLite | 零运维，后期平滑迁移 PostgreSQL |

## 5. 安全与隐私

- 所有个人数据（课表/笔记/日程）仅存本地/私有仓库
- 外部服务均走 OAuth 最小权限授权
- LLM 调用可配置为国内模型，数据不出境可选项
